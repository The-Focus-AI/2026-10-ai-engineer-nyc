Chapter 1 · Theme 07 thesis

The core shift across 5 talks

In institutional investing and private markets, off-the-shelf web chatbots fail on stale or conflicting inputs; agents earn front-office trust only atop governed firm ontologies, validated golden sources, unified MCP connectors, and hybrid code-ML-LLM-human pipelines that write synthesis back into the vault.

Every institutional finance talk located competitive advantage in governed data infrastructure and workflow design rather than raw model selection. Bridgewater contrasted an open-web chatbot answering a Korean won query from a single three-month-old note with Vault—which aligns 100M+ documents to a bitemporal ontology, serves 1,000+ QPS agent storms via turbopuffer cluster-local native filtering, migrates researcher email habits into saved collections, and writes human-agent workbench synthesis back into the corpus so knowledge compounds. At Apollo's Redding Ridge credit platform, engineers sat daily with portfolio managers to codify golden-source precedence across 20 conflicting systems, turning multi-hour weekly loan reconciliations into one-minute automated QA reports and cutting 200–400-name CLO portfolio construction from days in Excel to minutes for the first 80–90%. Coatue modeled the hedge fund as a composite state-machine function `(external_context, internal_context) -> (stock, size, timing)`, insisting that every pixel a human sees must be API-accessible while assigning each step whichever runner—deterministic code, classical ML, LLM, or human—maximizes quality. Exa supplied the external temporal layer with 400 billion dated web snapshots built for dense exploratory agent queries, while Anthropic standardized multi-system enterprise access behind a single MCP connectivity layer.

Vocabulary in the rooms: hedge fund as a function · bitemporal firm ontology · golden data sources · compounding investor workbench · hybrid code-ML-LLM-human runners

Chapter 2 · Evidence across 2 talks

Bitemporal vaults and dated web snapshots over stale open-web chat

In Vault: Making Unstructured Data Work for Investing (00:00:00), Aaron Linsky, Sam Green argued that bridgewater ingests over 100 million documents from 135 external sources plus internal memos and debate transcripts into Vault, enriching each document with ontology tags for countries, concepts, markets, and discussed time periods. In Vault: Making Unstructured Data Work for Investing (00:02:20), Aaron Linsky, Sam Green argued that on a live Korean won query, an open-web chat agent relied on one stale three-month-old note out of 15 results, whereas connecting the same agent to Vault time-scoped the search, matched 52 candidates, and synthesized seven current sources.

In Vault: Making Unstructured Data Work for Investing (00:06:23), Aaron Linsky, Sam Green argued that because production queries nearly always filter by date, source, or asset and agent storms exceed 100 to 1,000+ queries per second versus 100 per hour for humans, Bridgewater switched to turbopuffer's cluster-local native filtering to pair post-filtering speed with near pre-filtering recall. In Vault: Making Unstructured Data Work for Investing (00:09:34), Aaron Linsky, Sam Green argued that winning daily investor adoption required replicating familiar broker-email workflows inside Vault — converting distribution lists into saved searches and inbox folders into saved collections — before introducing cross-dataset queries, dynamic topic feeds, and CLI/Slack agent access.

In Vault: Making Unstructured Data Work for Investing (00:12:12), Aaron Linsky, Sam Green argued that the proactive Investor Workbench pairs always-on topic cards and raw source evidence with deep-research agents like Pocket Analyst, automatically writing the resulting human-agent synthesis back into Vault so institutional knowledge compounds across research cycles. In Search the Web as It Was: An Introduction to Exa Snapshot (00:00:00), Ryan Ahern argued that unlike humans who enter brief keyword queries and stop early, AI agents issue high volumes of detailed, exploratory searches per task, requiring search infrastructure purpose-built for agentic retrieval.

In Search the Web as It Was: An Introduction to Exa Snapshot (00:06:29), Ryan Ahern argued that by archiving page states during continuous freshness crawls, Exa Snapshot exposes over 400 billion daily-indexed web snapshots for both point-in-time URL lookups and historical semantic search queries.

Chapter 4 · Evidence across 1 talk

A hedge fund as a composite function across code, ML, LLMs, and humans

In A Hedge Fund as a Function (00:07:29), Frank Long argued that each sub-function should be assigned whichever runner—deterministic code, classical ML regressions, LLMs, or human judgment—maximizes absolute quality for that step rather than automating with LLMs by default. In A Hedge Fund as a Function (00:12:16), Frank Long argued that composing multi-step transformations across every firm data source with 10+ hyperparameters and 20+ values per node yields an effectively infinite graph whose core challenge is technical and organizational legibility.

In A Hedge Fund as a Function (00:01:25), Frank Long argued that agent capability is wasted unless every external market feed and internal firm record—positions, liquidity and risk constraints, and decades of trade decision notes—is exposed directly via API rather than UI copy-paste.

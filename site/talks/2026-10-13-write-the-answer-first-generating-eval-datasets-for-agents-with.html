Write the Answer First: Generating Eval Datasets for Agents With No Benchmark

Nathanael Weill, Air Canada

When an enterprise agent task has no benchmark and little expert access, start from a known answer (a source page, a rule, a template clause) and generate the input around it, so evaluation becomes automatic and iteration speeds up.
